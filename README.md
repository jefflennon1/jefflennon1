Redesigned batch processing to isolate record-level failures and investigated production incidents with Dynatrace. Also worked with AWS, Terraform and CI/CD.

**Banco do Nordeste · Enterprise modernization (via Kaspper)**  
Helped modernize three Java applications, migrating from IBM WebSphere to Open Liberty on OpenShift and upgrading from Java 8 to Java 21. Refactored complex legacy code and contributed to quality and security improvements across seven microservices.

**Health Solutions · Public healthcare systems**  
Developed and evolved Java/Spring applications used in municipal healthcare. Worked on e-SUS integration through Apache Thrift and batch processing, and provided technical guidance, onboarding and code reviews for developers.

**Esquadr.IA · Full-stack engineering and applied AI**  
Led web and mobile application development with Next.js, React, TypeScript and Flutter; deployed and maintained production infrastructure with Linux, Docker Compose and Traefik. Contributed to a Python/FastAPI backend using RAG, pgvector, Google Gemini, speech processing and payment integrations.
